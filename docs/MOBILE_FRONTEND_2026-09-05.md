# 手机端前端优化与验收（2026-09-05）

本次调整登录页、全局导航与筛选，以及经营总览、关键词流量、搜索排名、四象限、异常商品、退货、物流、补货选品、竞品雷达、账号管理十个模块的手机呈现与交互。桌面仍使用原有布局和图表坐标；后端、采集、数据库及统计口径不属于本任务的修改范围。

## 已完成

- 全局导航在窄屏使用抽屉，支持关闭按钮、遮罩、Escape、键盘焦点循环及关闭后焦点恢复。抽屉打开时锁定背景滚动，切换页面、屏幕尺寸变化和登录失效时正确关闭。
- 手机顶部显示当前模块与店铺，店铺、日期、前后区间切换和账号功能集中在可展开的“筛选 / 账户”区域；解决旧手机样式直接隐藏日期和店铺选择的问题。
- 手机输入控件使用可读字号和至少44px高度，长名称与说明换行，适配安全区域和动态视口；详情弹窗缩小标题区，底部关闭与平台链接保持可达。
- 十三个记录型表格增加手机字段标签及卡片布局，覆盖总览商品、退货/移除PO及明细、物流、补货选品、竞品审计/复核/退货/变体。原字段、数据绑定、操作和展开明细保留；需要横向比较的矩阵保留表格及局部横向滚动。
- 总览、关键词、竞品价格/库存/评论与自有商品销量图表按实际容器宽度绘制，减少手机刻度和重叠标签，支持轻点查数并保留纵向滚动。竞品手机图表使用分区标题，完整保留起止日期与时间。
- 自有商品销量保持原逐日数据、完整/截至采集/缺失状态、整数纵轴和独立日期范围；缺失日期不补0，零销量与缺失明确区分。宽度调整同时传入点击坐标换算，避免图形缩放后点错日期。

## 验证

- 前端完整测试：311/311通过；Vue类型检查与隔离生产构建通过。
- 新增手机销量几何测试：31个逐日点在四种窄屏图宽下保留所有值及缺失状态，首尾日期和整数刻度正确，逐点点击映射一致；另验证零值与缺失不混淆。
- 隔离Chrome合成数据验收：十个模块各检查320、375、390、430、768、844横屏、1440宽屏，共70个页面组合；另检查竞品详情及四种宽度的真实自有销量组件，共75项。没有整页横向溢出、页面渲染错误或业务写请求。
- 额外交互断言覆盖筛选入口、导航焦点循环/Escape/背景锁定、竞品及自有销量轻点查数、登录失效后恢复滚动和用户名禁用自动大写。
- 人工查看手机截图，修正详情顶部占用过高、移除PO标签截断和图表日期标签缺失问题。

验收使用合成样例，所有API请求均由本地测试拦截；没有使用真实账号或业务数据，没有发送保存、采集、刷新或其他写请求。`/api/competitors/batch-status`使用无活动批次的兜底样例，未测试运行中的批次状态。未完成真实iOS Safari、Android实体机、系统键盘弹出及全量真实业务数据的逐页验收。
