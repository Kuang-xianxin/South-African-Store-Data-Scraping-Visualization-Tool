## 发布期间的慢请求与修正

首次加载后发现一次严格读取超过 120 秒，随后 LAN 又出现 57 秒冷准备；这些失败没有从证据中删除。隔离 Git 工作树与正式源码的换行字节使缓存指纹不同，虽然代码及模型规范化后完全一致，预热不等于正式运行时复用。后续正式缓存已按当前指纹生成。
