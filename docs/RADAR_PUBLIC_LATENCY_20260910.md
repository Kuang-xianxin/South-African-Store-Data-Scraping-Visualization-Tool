# 蓝绿公网雷达加载核验（2026-09-10）

范围：蓝版8443加载慢、蓝绿数据库同步说明，以及用户追加的正式绿版443加载慢。没有启动新采集、业务数据覆盖、数据库合并或正式蓝绿切换。主页任务独立维护主页代码和静态发布，本任务协调雷达与网页重载。

## 原因与修改

- 蓝版腾讯到笔记本原网页上游走Tailscale洛杉矶DERP，RTT约344–352毫秒，云端health约1.5秒。新增两条独立、开机自启的SSH网页通道，仅绑定腾讯回环18505/18506，分别连接主机/笔记本8503；保留网页动态选择、任务归属和HMAC可信HTTPS标识。专用密钥限定节点及远端端口，原数据库/爬虫/正式GREEN18503通道不变。8443开启HTTP/2，记录不含查询参数、凭证的业务耗时日志。
- 真正竞品的库存观察以已存快照日期为准，移除单纯午夜引起的无条件缓存失效；自有商品的官方滚动销量仍按当天失效。权限、授权店铺、全局自有身份、所选日期与源码指纹边界保留。
- 前端原来同时发起两块列表，未选中的分区可能先抢到单个物化worker。现在首次计算先完成当前选中分区再读取另一块；true完整缓存预览可提前启动另一块，主请求失败也不阻止另一区读取，旧日期请求不能触发新的重读取。保留原1个worker/每批64个PLID、原事务完整性及全范围筛选/排序后分页口径。
